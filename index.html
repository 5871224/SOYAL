已知解析欄位

事件主封包可解析 Length、Function Code、Source Node、事件時間、Message Source、User Address、Sub Code、Sub Function、Extension Code、User Level、Door、卡號相關欄位與 checksum。100-byte File Base 後段另含 701Server/Client 寫入時間與管理欄位。

門號設定以 Node + 門號對應門名稱；使用者設定以 User Address 對應使用者名稱。兩者皆存於 VCF Supabase，修改後所有裝置共用。

目前設定 API 依你的要求開放所有人修改；未公開或尚未完全確認的 Offset 仍保留原始 HEX。
